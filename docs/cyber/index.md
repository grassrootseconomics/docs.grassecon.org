# Software

Grassroots Economics software supports Community Asset Vouchers, Commitment Pools, reports, maps, wallets, and public data. This section gives practical entry points for users, stewards, and developers.

## Current Cosmo-Local Credit entry points

The [Cosmo-Local Credit App](https://cosmolocal.credit) is the current supported public interface. Availability depends on the active deployment, asset, Pool configuration, role, device, provider, network, eligibility, jurisdiction, and published terms.

Common actions:

* Browse the App's [Market](https://cosmolocal.credit).
* Browse [Commitment Pools](https://cosmolocal.credit/pools).
* Start the supported [voucher-creation flow](https://cosmolocal.credit/vouchers/create/voucher) or [Pool-creation flow](https://cosmolocal.credit/pools/create/pool).
* Read [Getting Started](https://docs.cosmolocal.credit/introduction/getting-started) before creating an account or transacting.
